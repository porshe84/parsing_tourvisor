# Tourvisor Tracking Bot

Этот бот предназначен для автоматического поиска и отслеживания туров на сайте Tourvisor.ru. Он работает по следующим правилам:
- Ищет туры на месяц вперед от текущей даты (+7 дней интервал).
- Параметры поиска: вылет из Екатеринбурга в Турцию, 10 ночей, 2 взрослых и 2 ребенка (7 и 14 лет), отели 5*, рейтинг от 4.5, питание AI/UAI.
- Запускается два раза в день в 07:00 и 18:00 по московскому времени.
- Извлекает топ-15 самых дешевых вариантов и сохраняет их в базу данных SQLite (`tours.db`).
- Генерирует HTML страницу (`index.html`) с актуальным списком и датой последнего обновления.
- Отслеживает падение цен. Если цена на отель упала более чем на 5% относительно минимальной исторической цены в базе, выводится уведомление (симуляция отправки на почту и в Telegram).

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install requests schedule
   ```

2. Запустите бота:
   ```bash
   python3 tourvisor_bot.py
   ```
   Скрипт сразу выполнит первый поиск, обновит базу, сгенерирует `index.html` и перейдет в режим ожидания (цикл), чтобы выполнять последующие поиски по расписанию.

## Настройка уведомлений

В данный момент функции отправки уведомлений работают в режиме вывода в консоль (mock).
Для подключения реального бота Telegram, необходимо добавить токен и использовать `requests.post` для отправки сообщений в функции `send_telegram`.
Для подключения реальной почты, необходимо использовать модуль `smtplib` в функции `send_email`.
