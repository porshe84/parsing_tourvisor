# Tourvisor Tracking Bot

Этот бот предназначен для автоматического поиска и отслеживания туров на сайте Tourvisor.ru с удобным веб-интерфейсом. Он работает по следующим правилам:
- Ищет туры на месяц вперед от текущей даты (+7 дней интервал).
- Параметры поиска: вылет из Екатеринбурга в Турцию, 10 ночей, 2 взрослых и 2 ребенка (7 и 14 лет), отели 5*, рейтинг от 4.5, питание AI/UAI.
- Запускается два раза в день в 07:00 и 18:00 по московскому времени.
- Пропускает первые 10 самых дешевых отелей и выбирает следующие 15 вариантов.
- Позволяет добавлять отели для отслеживания вручную (по ID или ссылке) прямо через веб-интерфейс.
- Отслеживает текущий курс доллара ЦБ РФ.
- Сохраняет историю цен в базу данных SQLite (`tours.db`).
- Генерирует интерактивную веб-страницу (с графиком Chart.js и историей цен).
- Отслеживает падение цен. Если цена на отель упала более чем на 5% относительно минимальной исторической цены в базе, отправляется уведомление в Telegram.

## Установка и локальный запуск

1. Установите зависимости:
   ```bash
   pip install requests schedule flask
   ```

2. Задайте токен вашего Telegram-бота:
   ```bash
   export TELEGRAM_BOT_TOKEN="Ваш_Токен_Здесь"
   ```

3. Запустите Flask-приложение:
   ```bash
   python3 app.py
   ```

   Скрипт запустит локальный сервер, выполнит первый поиск в фоновом режиме и перейдет в режим ожидания расписания.
   Веб-интерфейс будет доступен по адресу `http://127.0.0.1:5001`.

## Настройка уведомлений Telegram

Чтобы бот смог отправлять вам уведомления о падении цен, вам нужно:
1. Создать бота через BotFather в Telegram и получить токен.
2. Отправить боту любое сообщение со своего аккаунта (например, `/start`).
3. Запустить скрипт с переменной окружения `TELEGRAM_BOT_TOKEN`. Бот автоматически найдет ваш `chat_id` и сможет присылать уведомления. (Либо вы можете явно передать `TELEGRAM_CHAT_ID`).
